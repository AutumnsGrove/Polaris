For "which side is right" questions where the honest answer is that serious people disagree. Not procon (one thing weighed) and not claim (one statement, a verdict). Deliberately no verdict, no strength meter: a model-invented "weight of evidence" number is exactly the unverifiable claim the sourcing rules exist to prevent. Each camp's sources are checked line by line like claim's evidence.

Each x/y line is one finished row, so the mapping fills in as it streams. The "breaks" line is the point of the block: an analogy that never says where it fails teaches something false. The prompt asks for it every time, and a block without one still renders (a missing line is just absent, never an error). Up to 6 pairs. It is the model's own device, so no source and no tick; an accent block like define, with no Oracle option.

What makes it send you to the sources, not around them:

  • Only pages Polaris opened. A line's URL must be one web_read fetched this turn, the same evidence set verification uses. Any other line is dropped and counted in the muted note at the foot. The model cannot recommend reading it never did.
  • "Opened by Polaris", the minutes and the page count are measured, not written by the model. They come from the page itself, counted at the moment web_read fetches it: the word count of the full extracted text, taken before the summarizing filter and before the display window trims it, at about 230 words a minute. What the model got back is never used: a two-line answer to a question says nothing about how long the page is. The model only writes the title, the level and one line on why.
  • Cases where a number would be wrong, so none is shown. A PDF shows its page count from the file (web_read extracts one page at a time, so there is no full text to count). A fetch that looks like a paywall stub or an empty JS shell shows no number at all, because "1 min" for a 15-minute article is the exact failure to avoid.
  • Order is the point. Levels render in a fixed order (start, next, deep) however the model emits them, at most 6 lines.
  • Ticks are local. Same rule as checklist: the page remembers nothing beyond the open tab.

highlight says "here are the best few things I found", cards you pick from. readings says "read these, in this order". The Oracle option text has to keep them apart, and a shopping answer should never fire it.
