1 · Icon

Finding Oracle's icon

Every icon here is either copied from the Lucide set the app already ships, or drawn on Lucide's grid (24px, 2px round stroke) so it sits next to them naturally. I skipped the icons already in use elsewhere in Polaris: Telescope, Compass, Orbit, Galaxy, Sunrise, Scan Eye, Eye, Sparkles, Star, Moon, Sun Moon and Target. Each card shows the icon large and at the 14px size it would have in the margin note.

3 · The whole turn

Playing it through

A full turn, timed roughly like a real one. The constellation gets one star per enabled check, lit in order. Change the count to see it scale. It folds into the margin note just as the first tool call arrives.

Sent
Checks:
Ibuprofen with lisinopril
Is it safe to take ibuprofen with lisinopril?
Ask Polaris…
More
  1. Sent. The ring in the composer starts turning. The stop button replaces send, as it does today.
  2. Reading. Faint stars appear under your message and light up one per check, and a line joins them. In reality Jev answers all checks in one request, so this is a fixed ~1s sequence that ends early if the first tool call arrives first.
  3. Resolved. The constellation shrinks into the icon's position and the note fades in beside it. Same place, same moment.
  4. Researching. Tool calls stream in underneath, unchanged from today.
  5. Answering. Prose streams as normal. Nothing about Oracle moves at this point.
  6. Done. The footer gets a new ⓘ button that opens the info sheet. Offer lines and follow-up suggestions appear last.
4 · The ⓘ sheet

Turn info, with a section per check

Opened from the new ⓘ in the turn footer, like Settings' usage stats. The top shows the answer's own numbers. Below that, each Oracle check that changed something gets its own card with the runner-up odds and the exact nudge text. Checks that ran but changed nothing are collapsed into one list.

Where it stands

  1. Icon: Asterism (custom). Ring: prism, turning while Oracle reads.
  2. Footer: cost moves into the ⓘ sheet, split into answer, verification and Oracle. Duration stays in the footer.
  3. Offers: 7a, separate lines under the footer, above the follow-up suggestions.
  4. Sheet order: the answer's stats sit above the Oracle sections.
  5. Note wording: kept as is for now; to be judged in real use.
  6. Focus modes: every nudge is checked against the active mode. Brief gets short variants, and Oracle never picks Brief on a high-stakes question. Safari needs the highest bar and holds for the whole thread.
