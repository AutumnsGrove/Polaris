What it is

A V8-isolate runtime at Cloudflare's edge — no cold-start container, code runs within milliseconds of a request landing at the nearest PoP. Comes up whenever the tradeoff against a long-running process is being weighed.

Durable Objects vs KV vs D1

Durable Objects for single-writer coordinated state, KV for eventually-consistent read-heavy config, D1 (SQLite) when relational queries matter more than global read latency.
