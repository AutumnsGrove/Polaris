Sidebar connection indicator

Today: an 8px dot, gold with a ring when the socket is open, red when it isn't — the same idiom as every status readout on the web. These four all signal by shape or position instead of hue, so they survive grayscale, colorblindness, and being glanced at on a phone at arm's length. Each is shown in the real 260px footer strip, in both states, plus a zoomed view of the mark alone.

Worth noting while judging these: down here means nothing runs — the agent loop, sending, streaming all dead until the socket comes back (ws.ts retries every 2s). So a down mark is allowed to be a little more present than a "nice to know" badge would be.

Why it isn't generic: the state is a position, not a color — the quietest of the four, and the only one that reads as a small illustration rather than a widget. Grayscale: star above vs. dipping through the line.

Why it isn't generic: nothing is drawn that isn't language. Smallest footprint of the four (~14px reclaimed for the text), and the only color anywhere is a 1px line, so it can never be mistaken for a notification badge — which the current dot already risks, sharing its exact shape and color with the Pulsar/Daily unread dots a few rows above it.

Watch: relies on the word, so the word had to get shorter — drop the ellipsis and use reconnecting; at 10.5px/0.14em tracking it still fits beside the three footer icons.

Why it isn't generic: motion carries the state — the only one of the four that catches the eye from across the room, which matters given down means "nothing works." Grayscale: upright vs. tilted, solid vs. dim.

Watch: a moving mark in a resting-state footer is the riskiest of the four. The wobble only runs while disconnected (never as ambient decoration), and it's slow — 5.4s, damped, not a spinner.

Pick a direction and it goes in web/src/lib/components/Sidebar.svelte's .status block — all four drop into the same flex slot the dot occupies now, need no new tokens (--color-accent / -2 / --color-danger only), and each is a single inline SVG plus two or three rules. All animation is suppressed under prefers-reduced-motion, and the up/down difference survives without it since it's shape, position, or fill — never hue alone.
