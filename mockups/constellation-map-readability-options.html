Design review

The Constellation map has stopped being a map

Both the full Map tab and the "Nearby in the constellation" mini-map on each star screen render every node's full title as always-on text, positioned only by a force simulation that keeps dot centers apart (26px on the full map, 20px in the mini-map) — it has no idea how wide a title's text actually is. Once a library holds more than a handful of stars, or a star has 2+ related neighbors, labels overlap into the unreadable block seen on-device. The fix isn't a tuning knob on the existing layout — it's picking a different way to show which star is where without stacking every title on top of the next one.

0px of collision margin reserved for label text width
90px tall mini-map canvas, no ceiling on neighbor count

Mechanism: dots and connecting lines only, by default. Tapping one star lifts a single label chip above it; everything else stays quiet.

Tradeoff: matches the "night sky" feel most directly, but browsing titles takes one tap per star instead of a glance.

Mechanism: only category names are ever rendered as text — member stars are plain glowing dots inside their category's halo. No per-star label exists to collide with another.

Tradeoff: reads instantly at any density; a star's own title still needs a tap (or the Library list) to read — same cost as option 1, paid for a much steadier map.

Mechanism: same idea as the list, drawn as a diagram — the center star anchors the left edge, neighbors are placed one per fixed row height (never simulated), each label sitting beside its own dot on its own line.

Tradeoff: keeps the fan-out, connected-stars visual the feature is named for, at the same engineering cost as the plain list — no physics to fight.

Recommended pairing

Category orbitals (2) for the full map — it's the only option that scales structurally as the library grows past a few dozen stars, not just at today's size — paired with tap-to-reveal for reading an individual star's name once a cluster is narrowed down. For the mini-map, fixed radial rows (B) costs the same as the plain list but keeps the "nearby in the constellation" diagram actually looking like one.

Say which combination to build — full map and mini-map choices are independent of each other.
